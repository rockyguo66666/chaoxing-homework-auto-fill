# 排版手感与破绽清单

## 一、抖动（jitter）参数

字体天然整齐，真人手写有波动。`render.py` / `answer_sheet.py` 逐字施加：

| 档位 | 旋转 | 位移 | 字号 | 字距 | 什么时候用 |
| --- | --- | --- | --- | --- | --- |
| `none` | 0 | 0 | 0 | 0 | 只要字库，不要"像手写" |
| `low` | ±0.8° | ±1.8% | ±1.0% | ±1.0% | 字迹本来就工整的人 |
| `mid`（默认） | ±1.6° | ±3.5% | ±2.2% | ±2.0% | 大多数人 |
| `high` | ±2.6° | ±5.5% | ±3.5% | ±3.0% | 字迹潦草，或要刻意"不齐" |

注意：抖动是**逐字**的，所以相邻两行不会同步，视觉上是真的乱，不是整体倾斜。

## 二、其他手感开关

| 开关 | 建议 | 说明 |
| --- | --- | --- |
| `--paper-style scan` | 想更真时 | 加一点模糊，像扫描件 |
| `--ink-color 32,32,44` | 默认 | 中性偏蓝的黑，圆珠笔/中性笔的常见色 |
| `--ink-alpha 0.85` | 想更淡 | 整页墨色浓度 |
| `--rules line` | 横线本作业 | 横线画在纸层，字压在线上 |
| `--line-spacing 1.5–1.7` | 别用 1.0 | 真人不会把行挤满 |
| `--chars-per-line 26–32` | A4 上 | 换算下来字高约 6.5–7.5mm，接近真人手写尺寸 |

## 三、会被一眼看穿的破绽（按显眼程度排序）

1. **同一标点每次一模一样**——最明显。句号、逗号、顿号在一页里出现几十次，
   每次都同一个形状、同一个倾角。
   → 解法：让用户把常用标点各写 2–3 遍（采样纸里手动加格子），文件名存成 `，_2`，
   目前 `build_font.py` 每字只取一个样本，多样本轮换还没实现。
2. **基线过齐**——所有字坐在同一条水平线上，间距还均匀。
   → 解法：`--jitter mid` 以上；`--line-spacing` 别用整数倍。
3. **墨色完全一致**——真人写字有起笔重收笔轻、有笔压变化。
   → 目前没实现笔压模拟，这是已知短板。想补的话：逐字给 alpha 加 ±8% 的随机。
4. **纸张太干净**——没有折痕、没有装订孔、没有渗墨。
   → 目前的纸感只有低频不匀 + 颗粒 + 暗角。要更像，可以叠一层真实纸张纹理图。
5. **字与字之间的照应**——真人有连笔、有牵丝、有大小相让。
   → 字体结构上做不到，只能靠抖动掩盖。
6. **整页节奏均匀**——真人是前面写工整、后面越写越潦草。
   → 可以后期实现：按行号递增 jitter。目前没做。

**结论**：单页近距离盯着看，一定看得出来是字体；隔一张桌子看、或者跟一沓真迹混在一起，
基本没问题。要真正抗检，得用真迹——这也是路线 A 值得推荐的原因。
