# 手写体作业（个人字迹仿写）

把**用户自己的笔迹**变成可复用的字库，再把任意答案排成一张像他亲手写的答题纸。
全流程本机离线跑，依赖只有 numpy + Pillow + fontTools。

## 先做一件事：确认走哪条路线

| 路线 | 什么时候用 | 用户要写多少字 | 保真度 |
| --- | --- | --- | --- |
| **0 现成手写体（零采样）** | 用户嫌自己字丑 / 不想写采样纸 | **0** | 不是他的字，但立刻能用 |
| **A 按需采样（推荐）** | 作业答案字数已知（简答题几乎都是） | 只写答案里出现过的字，通常 150–400 个 | **100% 真迹** |
| **B 常用部件表** | 想以后随便写什么都像自己 | 320 个（assets/常用部件表.txt） | 真迹 + 部件拼接 |
| C FontDiffuser | 要覆盖 3500 常用字 | 100–300 个 | AI 生成，最不像，最费机器 |

**先问一句「要不要用你自己的字」**：
- 用户愿意写 → 走 A，出来是 100% 真迹，效果最好；
- 用户嫌自己字丑 / 不想写 → 走 0，直接从本机现成手写体里挑一个，**零采样、当场出图**。

路线 C 见 references/FontDiffuser路线.md，本机未验证，谨慎承诺。

## 路径约定

- `<工具目录>`：本 SKILL.md 所在目录，`scripts/`、`assets/`、`references/` 都在这里。
- `<作业目录>`：当前工作区下新建的目录（如 `手写作业/`），采样纸、照片、数据、成图都放这里。
- **不要往 `<工具目录>` 里写用户数据。**

## 最短可用流程（路线 A）

```bash
cd <工具目录>/scripts
python3 doctor.py                                              # 环境自检，先跑

# 1) 用答案文本生成采样纸（自动去重出所有用到的字）
python3 make_template.py --from-text <作业目录>/答案.txt --out <作业目录>/采样/

#    → 让用户：打印 → 用平时的笔逐格照写 → 整页拍照（四角黑块入镜）
#    → 拿到照片后：

# 2) 拍照 → 切字
python3 preprocess.py --photo <作业目录>/页1.jpg --template <作业目录>/采样/manifest.json --out <作业目录>/data
#    → 打开 <作业目录>/data/qc/contact_sheet.png 肉眼确认切字质量（这一步不许跳过）

# 3) 位图 → TTF
python3 build_font.py --data <作业目录>/data --out <作业目录>/myhandwriting.ttf --verify 30

# 4) 答案 → 手写答题纸
python3 answer_sheet.py --qa <作业目录>/作业.txt --font <作业目录>/myhandwriting.ttf \
    --out <作业目录>/答题.png --title "物理简答题" --rules line --report <作业目录>/渲染报告.md
```

## 路线 0：用现成手写体（零采样，最快）

**当前用户选的是「娃娃体」，预设名就叫 `娃娃体`。** 以后每次出图：

```bash
cd <工具目录>/scripts
python3 answer_sheet.py --preset 娃娃体 --qa <作业目录>/作业.txt \
    --out <作业目录>/答题.png --title "简答题" --report <作业目录>/渲染报告.md
```

换字体只要换预设名（`--list-presets` 看全部：翩翩体/手札体/楷体/行楷/雅痞/魏碑/隶变/圆体）。
预设表在 `assets/presets.json`，存的是**字体文件名**而不是绝对路径——
AssetsV2 里的 hash 路径会变，写死了迟早失效，运行时用 `find_font_file()` 现找。
命令行参数永远覆盖预设同名项。

**给用户挑字体时**（照旧用这两个脚本）：

```bash
python3 list_fonts.py --json /tmp/fonts.json          # 列出本机手写体候选（自带真实覆盖率）
python3 font_samples.py --from-json /tmp/fonts.json --out <作业目录>/候选/   # 出对比样张
```

**必须如实告诉用户**：这条路线出来的不是他的字，是某个字体的字。
对于「字丑」的场景这是合理的取舍，但不要含糊成「按你的字迹生成」。

常用候选（macOS 自带，简体覆盖 100%）：翩翩体（HanziPen，最像学生手写）、
手札体（Hannotate，钢笔感）、楷体（Kaiti，端正但偏印刷感）、行楷（Xingkai，成熟）。
macOS 的 .ttc 是字体集合，**必须用 `--font-index` 选对脸**，不然拿到的是繁体版。

## 缺字怎么办（不许含糊过去）

渲染时如果答案里有字没写过，按优先级处理，并且**必须告诉用户是哪几个字**：

1. **让用户补写**（首选）：把缺字重新生成一张采样纸，补写后重跑 preprocess + build_font。
2. **部件拼接**：`fetch_ids.py` 拉部件表 → `compose.py` 用用户写过的部件拼。
   拼出来的字**不是真迹**，会被记进 `composed.json`，渲染报告里单独列出。
3. **楷体顶替**：`--fallback-font auto`（默认开）。报告里会写「N 个字是楷体顶替」。
4. **留白**：`--fallback-font none`，缺字直接不写。

**绝不允许**把楷体顶替或部件拼接的字说成「你的字迹」。报告里怎么写的就怎么转述。

## 硬性纪律

- **合规先问**：用途是「把 AI 仿手写当手写作业交」时，先说一句「确认下学校/老师允许不允许」，
  一句话带过即可，别上纲上线；用于笔记、练习、老师出材料则无此顾虑。
- **质检图必须看**：`data/qc/contact_sheet.png` 是切字质量的唯一凭证。
  不看就往下走，等于把废字库打进字体里。用看图能力（本机可用 OpenClaw + 智谱视觉模型）确认。
- **自检要跑**：`python3 selftest.py` 会用合成手写跑通全链路并给 IoU，改过脚本后务必重跑。
- **不要声称验证过没验证的东西**：路线 C 本机从未跑通。
